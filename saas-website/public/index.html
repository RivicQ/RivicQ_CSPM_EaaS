🚀 Quick Start Integration

# Clone the main repository
git clone https://github.com/rivic/q-runtime.git
cd q-runtime

# Deploy to Kubernetes
kubectl apply -f k8s/manifests.yaml

# Enable quantum-safe mode for your namespace
kubectl label namespace your-app rivic-injection=enabled

# That's it! Your apps are now quantum-safe 🎉
