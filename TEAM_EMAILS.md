# RivicQ Team Email Aliases

All RivicQ mailboxes live on the **`rivicq.com`** domain. Below is the canonical list of email aliases to be created for the core RivicQ team and their routing.

## Core team mailboxes to create

| Email | Purpose | Routing to |
|---|---|---|
| `hello@rivicq.com` | General inquiries / first contact | Founders / Office of the CEO |
| `admin@rivicq.com` | Platform administrator (demo + enterprise admin bootstrap) | Platform Engineering |
| `enterprise@rivicq.com` | Enterprise sales, POC requests, procurement | Sales / Enterprise Solutions |
| `sales@rivicq.com` | Sales pipeline and demo requests | Sales |
| `engineering@rivicq.com` | Engineering escalations, SDK/integration support | Engineering Lead |
| `devops@rivicq.com` | Deployments, infrastructure, CI/CD | DevOps / SRE |
| `sre@rivicq.com` | Site reliability, on-call, incident response | SRE on-call |
| `security@rivicq.com` | Security disclosures (CVD), audit, compliance | Security Lead |
| `conduct@rivicq.com` | Code of Conduct reports, community health | Community / HR |
| `privacy@rivicq.com` | Data privacy requests (GDPR), DPA | DPO / Legal |
