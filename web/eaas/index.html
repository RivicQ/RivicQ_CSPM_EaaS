Architecture and custody

Caller identity is derived from the credential stored server-side, never from a client-supplied tenant header. API credentials are stored as SHA-256 hashes and shown once. Keys used for cryptographic operations are generated server-side and never returned. Payloads, plaintext and secrets are excluded from usage events and logs. The standalone service uses an atomic file store for sandbox use; hosted deployments must use the PostgreSQL migration in deploy/migrations/004_eaas_schema.sql.
