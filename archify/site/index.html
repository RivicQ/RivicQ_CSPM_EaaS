Product facts

A posture you can inspect and keep.

What is RivicQ?

RivicQ is Cryptographic Security Posture Management. Community (Apache-2.0) inventories cryptography (CBOM) and software components (SBOM); Enterprise licenses the QBOM, HBOM, AIBOM, and IBOM control-plane layers. Every diagram on this page is a validated Archify artifact generated from repository evidence — it documents the product described in the README and the code.

What can I provide as input?

A repository, a directory, a TLS endpoint, a declared pod or server, firmware or identity artifacts — and in Enterprise, customer cloud credentials via connectors. You can also point an agent at the RivicQ codebase to redraw any map. Missing facts are marked in the diagrams, never invented.

Which edition is open source?

Community is this public GitHub project, usable, modifiable and distributable under Apache-2.0. Enterprise is a commercial license from RivicQ GmbH. Editions are licenses and feature entitlements — not a second scanner; both share the engine.

What do I receive, and what are the limits?

Each diagram is an HTML file with inline SVG plus its typed JSON source. Validation checks the diagram against an authoring contract; it does not prove runtime behaviour, and RivicQ claims no certification, audit opinion, or legal advice. Framework names in the UI are control mappings for operators, not seals of approval.

Exports include PNG, JPEG, WebP, SVG, and WebM. Availability depends on the format and browser or local tooling; open any artifact and check its export menu before choosing a delivery format.
