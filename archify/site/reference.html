Operator console

Dashboard, assets, findings, scanner, BOM, governance, and role-gated admin views use a real API session. MFA setup and disable require `/auth/me` identity and a live API.

Tenant-scoped engine

POST /scans returns 202 with a result URL. Status and report reads stay inside the caller tenant; unmapped mutations fail closed.

Edition boundary

Enterprise fails closed without a valid license and configured database. Unconfigured cloud, HSM, SSO, and advanced BOM layers stay unavailable.

Editions and truthful boundaries

One engine, two editions. Community runs locally and in CI; Enterprise controls cloud attach, advanced BOM layers, SSO, audit, and continuous monitoring.

Community · Apache-2.0

  • CLI, GitHub Action, dashboard, and scanner
  • CBOM from repository, host, website, SBOM, firmware, and inventory targets
  • CycloneDX-compatible evidence and policy decisions
  • No cloud credentials or advanced BOM layers granted by cloning

Enterprise · license required

  • QBOM, HSM/PKCS#11, SSO, RBAC, and audit
  • Continuous production monitoring and cloud connectors
  • AIBOM, IBOM, and governance evidence packs
  • DORA, NIS2, NIST, ISO, PCI, and SOC 2 mappings are not certifications
