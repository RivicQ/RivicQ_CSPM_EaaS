# Dashboard audit

Command Center Overview (`/dashboard`) is an inbox, not a chart wall.

Live mode: inventory/CSPM/compliance APIs when `hasLiveTelemetry()`. Demo mode: labeled simulation. Community with no scans: empty onboarding (no simulation mixed in).

KPI “Open findings” navigates to `/findings`. Queue items open the findings page with `id`.

Charts still answer “is posture moving?” only when the adapter has a trend series — in demo that series is simulated and chipped DEMO.
