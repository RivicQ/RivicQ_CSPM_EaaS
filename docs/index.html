What is actually live

Honest capabilities. Cloud connectors and quantum APIs need customer credentials.

Discover → mitigate → report
Website, host, IP, server, declared Kubernetes pods, and QSIC/HSM catalog. PQC mapping to ML-KEM/ML-DSA. Community JSON; Enterprise DORA pack.
GitHub content scan
SAST/secrets/SCA-style regex overlay and CBOM when an API is reachable. Pages fails honestly without an API.
Policy gate
CLI and GitHub Action can fail CI on BLOCK findings. RSA-2048 is classified, not auto-vulnerable.
PQC mapping
Migration planning toward ML-KEM / ML-DSA. Optional quantum-provider hooks when you supply an API key — never a hard dependency.
Cloud & HSM connectors
Enterprise inventory for AWS, Azure, GCP, and other cloud connectors when credentials are configured. Empty when disconnected.
Compliance mappings
Operator mappings (ISO, NIS2, DORA, BSI, NIST, and others). Not an audit opinion or a certification of RivicQ GmbH.
SSO & RBAC
Enterprise JWT roles (Viewer, Analyst, Operator, Admin). SAML ACS completion is an operations task with your IdP.
Known limitations
Pages has no production API. eBPF/Cilium is an optional integration, not a shipped kernel program.
