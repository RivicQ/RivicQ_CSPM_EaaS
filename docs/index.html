Discovery to migration

The engine classifies cryptographic posture. It does not rotate production keys. Community stops at JSON evidence. Enterprise adds continuous monitoring and contracted packs.

01 · Discover

Inventory the estate

Scan a public GitHub repo, website, or host with rivicq scan or the labeled console field. Algorithms, certificates, and declared secret names — never secret values.

02 · Assess

Build the bills of materials

CBOM / SBOM / local QBOM. Qiskit scores are a local taxonomy — not IBM Quantum hardware. RSA-2048 is classified; it is not treated as automatically broken.

03 · Remediate

Gate, then patch

The GitHub Action can fail CI on BLOCK findings. Operators apply patches. The product does not silently rewrite keys or destroy cloud resources.

04 · Migrate

Plan classical → PQC

Harvest-now-decrypt-later exposure is scored. Hybrid ML-KEM / ML-DSA is the recommended cut-over. Migration is an operator decision, not an automatic rotation.

05 · Report

Evidence, then packs

Community exports JSON. Enterprise adds DORA-oriented evidence packs and audit history under a commercial contract. Mappings are not certifications.
