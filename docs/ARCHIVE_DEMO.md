# Archived Demo Fixtures

The project previously included seeded demo fixtures for local development and demos. These fixtures are preserved for reference only and are not used in live or CI builds.

Location:
- demo/fixtures/

Notes:
- Runtime demo endpoints under `/api/v1/demo/*` are disabled in live builds.
- To run the legacy demo server, extract fixtures from `demo/fixtures/` and run the mock API in an isolated environment.
- Prefer using real inventory and compliance endpoints for development and CI.
