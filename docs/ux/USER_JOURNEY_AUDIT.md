# User journey audit

A — New customer: signup works on API; first scan is the scanner; dashboard empty state is honest. Skip is available via Try labeled demo.

B — Analyst: Overview queue → `/findings` evidence panel → related assets query. Verify = rescan. Assign is unavailable (not faked).

C — CISO: persona hides scanner chrome; KPIs drill to findings; reports = Analytics. Executive PDF builder is P2.

D — PQC: CBOM explorer list + migration hub from scan intelligence. No fabricated effort.

E — DevSecOps: `/tools` PATH probe + CLI. Policy gate on scan complete. CI is GitHub Action, not an in-app pipeline run list.

F — Admin: `/admin` users, audit, keys, webhooks, SAML store. Live SSO handshake is operations work.
